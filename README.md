# MediBuddy

MediBuddy is a simple medicine search application that allows users to search for medicines and view detailed information using the FDA Drug Label API.

## Live Demo

https://medi-buddy-olive.vercel.app/

## Tech Stack

- React
- Node.js
- Express.js
- FDA Drug Label API

## Features

- Search medicines by brand name
- View detailed medicine information
- Recent searches
- Responsive interface
